This program is meant to assemble an assembly program into binary based off a given ISA.

This program is meant to assist in the creation of Instruction Set Architectures, otherwise known as ISAs.

# Test.lua

This program is will generate two 8-bit integers and show you what the output of each operation with those two integers should look like in decimal, hexadecimal and binary.
